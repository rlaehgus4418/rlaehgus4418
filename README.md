<br>

> 부족함을 두려워하지 않고, 긍정적인 에너지로 팀에 기여하며 끝까지 해내는 팀플레이어 개발자입니다.

- 아직 배울 것이 많다는 점을 인정하고, 빠르게 흡수해 더 나은 결과로 연결하려고 합니다.
- 팀의 흐름이 끊기지 않도록 자주 소통하고, 맡은 일은 책임감 있게 마무리합니다.
- 모르는 부분은 회피하지 않고 직접 부딪혀 해결하며, 꾸준히 성장하는 과정을 즐깁니다.
- 밝은 분위기로 함께 일하기 편한 팀원이 되는 것을 중요하게 생각합니다.
- 사용자 흐름과 화면 경험을 고민하며, 작은 기능도 완성도 있게 구현하려고 노력합니다.

<br>

### What I Can Contribute

- 문제를 “누군가 해주겠지”가 아니라 “제가 해볼게요”로 바꾸는 적극적인 태도
- 진행 상황을 꾸준히 공유하고 맞춰가는 협업 중심의 작업 방식
- 작은 기능도 동작하는 상태로 끝까지 완성하려는 끈기와 책임감
- 피드백을 빠르게 반영하며 개선하는 성장 지향적인 자세
- 팀 분위기에 자연스럽게 녹아들고, 긍정적인 에너지로 함께 일하는 태도
